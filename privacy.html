Privacy

A straightforward overview of how this static calculator site handles the values you enter.

Calculator inputs

The calculators in this version run in your browser. Values entered into calculator fields are used to produce the result on the page and are not intentionally sent to a Calculate This server for calculation.

Hosting and third parties

The website is hosted using third-party infrastructure, so normal web requests can involve technical information such as IP addresses and browser details being processed by the hosting provider. The site also loads web fonts from Google Fonts.

Analytics

This page does not promise that analytics will never be added. If measurement or advertising technology is introduced later, this privacy information should be updated to describe it accurately before relying on this statement.

Sensitive information

Do not treat a calculator field as a secure place to store sensitive personal information. The tools are designed for calculations, not record keeping.
