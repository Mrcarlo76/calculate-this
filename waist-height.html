Waist-to-Height Ratio Calculator guide

Simple ratio

Waist-to-height ratio = waist circumference ÷ height.

Same units

Centimetres or inches both work as long as waist and height use the same unit.

Context matters

A single body measurement cannot describe overall health on its own.

Frequently asked questions

Do waist and height need the same unit?

Yes. Use centimetres for both or inches for both.

Does this diagnose health conditions?

No. It is only a body-measurement ratio.

Can I use inches?

Yes. Because it is a ratio, matching units cancel out.
